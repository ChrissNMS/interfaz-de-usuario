Proyecto de alarmas para pagar servicios

Esta fue una aplicación diseñada para gestionar y programar recordatorios para el pago de servicios (luz, agua, internet, etc.). El objetivo principal es ayudar al usuario a evitar olvido y cargos por demora, enviando notificaciones antes de las fechas de vencimiento.
